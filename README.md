# 🤖 AskBuddy - AI QnA Bot

**AskBuddy** is an interactive, context-aware AI conversational chatbot built with **Streamlit**, **LangChain**, and **Google Gemini AI**. 

It provides a modern chat interface where users can ask questions and engage in multi-turn conversations while preserving session history.

---

## 🚀 Features

* **Context-Aware Conversations:** Retains chat history within the session to provide accurate, context-aware responses.
* **Modern UI:** Clean and intuitive chat interface built with Streamlit's native chat components.
* **Powered by Gemini:** Leverages Google's fast and capable Gemini generative model via LangChain integration.
* **Environment Configuration:** Uses `python-dotenv` for secure local API key management.

---

## 🛠️ Tech Stack

* **Frontend / UI:** [Streamlit](https://streamlit.io/)
* **AI Framework:** [LangChain](https://www.langchain.com/)
* **LLM Provider:** [Google Gemini API](https://ai.google.dev/) (`langchain-google-genai`)
* **Environment Management:** `python-dotenv`

---

## 📋 Prerequisites

Before running this project, ensure you have:

* **Python 3.9+** installed on your system.
* A **Google Gemini API Key** (You can get one for free from [Google AI Studio](https://aistudio.google.com/)).
